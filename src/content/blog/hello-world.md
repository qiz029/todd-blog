I've been meaning to start a blog for approximately eight years. Today it finally happened — not because I had some grand revelation, but because a Saturday evening conversation with my AI agent turned into scaffolding an Astro site, buying a domain, and shipping it in under an hour.

The friction was the only thing stopping me. When "publish a blog post" means:

1. Open Obsidian
2. Write markdown
3. `git push`

...there's really no excuse anymore.

## What to expect

I'll write about software engineering — compilers, programming languages, distributed systems. Things I'm building. Things I'm reading. Probably some rants about code readability and why naming things matters more than we admit.

No comments section (for now). No newsletter. No analytics. Just text on a page, the way the web was meant to be.

## How this works

This site is built with [Astro](https://astro.build), deployed to [Cloudflare Pages](https://pages.cloudflare.com), and every post is a plain markdown file in a git repo. No database. No CMS. No server. Just static HTML on a CDN.

If you're reading this, it worked.
